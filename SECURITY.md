# Política de seguridad

- Los binarios se descargan únicamente desde el endpoint de releases del proyecto comunitario indicado en la interfaz.
- Se exige el digest SHA-256 publicado por GitHub para el asset concreto.
- El instalador no ejecuta scripts de instalación remotos, no usa sudo y no modifica rutas del sistema.
- La compilación AppImage es de terceros y no está respaldada por Anthropic. Revise el origen antes de instalarla.
- No introduzcas contraseñas ni tokens en incidencias públicas.
